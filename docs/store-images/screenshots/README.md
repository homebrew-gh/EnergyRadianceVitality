# Store screenshots (phone)

Add **in-app** screenshots here (ERV running on a device or emulator). Zapstore picks up any `.png`, `.jpg`, `.jpeg`, or `.webp` in this folder via `zapstore.yaml`.

Use clear names, for example:

- `dashboard.png`
- `workout.png`
- `settings-nostr.png`

**Do not** use captures of the Zapstore or GitHub web UI as “screenshots”; they are listing metadata, not product shots.

After adding files, commit, push, and run `zsp publish` again so assets upload to Zapstore’s CDN.
